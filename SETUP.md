# Setup notes (delete this file once done)

Three images in the README are generated automatically by GitHub
Actions from your live contribution activity — they cannot be
created as static files ahead of time:

1. **profile-3d-contrib/profile-night-rainbow.svg**
   Generated by `.github/workflows/profile-3d-contrib.yml`
   (uses the yoshi389111/github-profile-3d-contrib action).

2. **snake.svg** (referenced from the `output` branch)
   Generated by `.github/workflows/snake.yml`
   (uses the Platane/snk action).

3. **All the `github-readme-stats`, `streak-stats`, `trophy`,
   `profile-summary-cards`, and `komarev` widgets in the README**
   are hosted services — they pull live data on every page view.
   No setup needed, but they'll look sparse until your GitHub
   account has more public activity.

## To activate #1 and #2

1. Push this repo to **github.com/AlaminM01/AlaminM01**
   (the repo name must exactly match your username).
2. In the repo, go to **Settings → Actions → General → Workflow
   permissions**, and set it to "Read and write permissions".
3. Go to the **Actions** tab and manually run both workflows once
   ("Run workflow" button) — after that they'll run daily on their
   own via the cron schedule.
4. Wait a minute or two, refresh your profile page, and the
   graphics will appear.
