# Security Policy

This repository powers my GitHub profile README (github.com/AlaminM01)
and contains no application code, so there are no software versions to
track for security updates.

## Reporting a Vulnerability

If you spot a broken link, an exposed secret, or anything else that
looks like a security issue in this repository, please reach out:

- Email: alaminmondalce@gmail.com
- LinkedIn: [linkedin.com/in/alaminmondal1](https://linkedin.com/in/alaminmondal1)

I'll acknowledge reports within a few days and fix confirmed issues
as soon as possible.
